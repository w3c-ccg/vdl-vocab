This specification describes an experimental vocabulary for expressing a Verifiable Driver's License, which is intended to be fully conformant with the ISO 18013 Mobile Driver's License data model.

Alternate versions of the vocabulary definition exist in Turtle and JSON-LD.

This document is experimental.

Introduction

This specification describes an experimental vocabulary for expressing a Verifiable Driver's License, which is intended to be fully conformant with the ISO 18013 Mobile Driver's License data model.

Use Cases and Requirements

The following use cases outline a number of key scenarios that readers might find useful:

  • Expressing driving privileges on the Web.
  • Serializing driving privileges in an optical carrier (e.g., QR Code).
  • Selectively disclosing driving privileges.
  • Compatibility with the W3C Verifiable Credentials data model.

The Verifiable Driver's License AAMVA Vocabulary

The Verifiable Driver's License AAMVA Vocabulary extends this vocabulary with terms for all data elements defined by the mDL Implementation Guidelines issued by the American Association of Motor Vehicle Administrators (AAMVA). It can be imported as a JSON-LD context behind the URL https://w3id.org/vdl/aamva/v1.

The AAMVA vocabulary matches the data element set in Version 1.2 of the AAMVA mDL Implementation Guidelines, released on 22 November 2022.
