This vocabulary extends the Verifiable Driver's License Vocabulary with terms for all data elements defined by the mDL Implementation Guidelines issued by the American Association of Motor Vehicle Administrators (AAMVA).

The terms match the data element set in Version 1.2 of the AAMVA mDL Implementation Guidelines, released on 22 November 2022. Data elements that later versions add are not part of this vocabulary.

Alternate versions of the vocabulary definition exist in Turtle and JSON-LD.

This vocabulary is published together with the Verifiable Driver's License Vocabulary. Comments are welcome as GitHub issues.
